## Retention

Retain original source archives, every referenced immutable release, registry/implementation dependencies, source hashes and published research lineage indefinitely. No automatic archive/canonical garbage collection is enabled. Derived query/job caches are reproducible and may be pruned under an explicitly scoped maintenance policy after active jobs and research references are checked; none were bulk-deleted in this delivery. Never apply a broad lifecycle expiry to gold/sec-engine/releases. Account for retained draft/evaluation releases separately from the roughly380MB current native release. Rotating the private bearer changes HMAC cache/cursor validity; plan a fresh release/cache namespace rather than silently ignoring failed integrity checks.

The pipeline uses four bounded I/O prefetch tasks and one financial-calculation thread. Independent DuckDB uses one thread/64MiB and per-company batches. It reads already stored public SEC members; it does not start the WRDS collector or extract the whole archive. Full-universe processing must continue in measured bounded batches, preserving source failure isolation.

## Cost model

Current R2 Standard list rates are$0.015/GB-month,$4.50/million ClassA and$0.36/million ClassB, with included usage and whole billing-unit rounding ([R2 pricing](https://developers.cloudflare.com/r2/pricing/)). Cached ordinary histories perform four ClassB reads (root,shard,pinned company,query cache), about$1.44 per million requests before allowances/rounding; misses add immutable cache writes/readback. Two reads per screen imply$0.72 per million before allowances. These are operation scenarios, not the account bill. Retained historical/draft releases and growing query caches add storage.

Workers Standard adds$0.30/million requests and$0.02/million CPUms beyond included allocations ([Workers pricing](https://developers.cloudflare.com/workers/platform/pricing/)). Measured CPU samples and API latency are in benchmarks.json; extrapolate from those samples only as scenarios, not anSLO. Queue operations and operator Basin SQL/catalog scans are additional. [Basin SQL pricing](https://developers.cloudflare.com/basin-sql/platform/pricing/) is$0.0025/GB scanned with10MB/query minimum and10GB/month included; measured scans require the minimum where applicable. Basin scan bytes/file counts are recorded exactly; no runtime Basin query is needed for ordinary histories or screens.
