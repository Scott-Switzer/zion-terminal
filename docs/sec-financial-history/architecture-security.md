# Decision: explicit native SEC history, independent Basin verification

Use hash-pinned native public SEC JSON in the existing private Worker with R2 bindings for this endpoint. The release pins registry, implementation and temporal dependencies. Validate source hashes before querying and expose engine `NATIVE_IMMUTABLE_SEC_HISTORY`. This is an explicit architecture choice, not a runtime fallback from Basin. No new SQL credential is installed, and the existing pilot remains unchanged.

Basin SQL supplies independently verified cross-table joins on two isolated public-only Iceberg tables. Raw Parquet objects are not presumed registered tables. The available operator token can write its pilot namespace, so it is unsuitable as proof of least privilege. DuckDB is an offline independent calculator with one thread, 64 MiB and external access disabled; it is not a deployed fallback. Native reads avoid broad SQL privileges but require bounded per-company objects and explicit mappings; Basin would allow larger joins after credentials pass; DuckDB hosting would add compute and lifecycle overhead.

Cloudflare documentation conflicts: [Basin query setup](https://developers.cloudflare.com/basin-sql/query-data/) recommends broad storage/write setup, while the [read-only Catalog announcement](https://developers.cloudflare.com/changelog/post/2026-07-09-r2-data-catalog-read-only-tokens/) supports Catalog Read plus Storage Read for SQL engines. [R2 token documentation](https://developers.cloudflare.com/r2/api/tokens/) supports scoped read permissions. Candidate policy: SQL Read, Catalog Read, Bucket Item Read scoped to the public pilot bucket. This remains a candidate, not a verified minimum: both locally available operator and OAuth credentials received 403/9109 when provisioning. Safe local filename/variable searches found no additional administrator credential. The browser dashboard session reached account home but returned a refresh error, providing no new permission evidence.

Authentication precedes source reads. The route selects only manifest-approved CIKs and public SEC metrics; there is no arbitrary SQL, caller object path, or licensed dataset enablement. Existing broad backend binding is not called by this endpoint. Integrity hashes are server pinned. Responses are private/no-store and vary on Authorization. Source nulls, rejected contexts, duplicate contradictions, and unsupported mappings cannot silently revive older values or become zeros. Any accepted debt calculation requires scope-aligned explicit components.

Custom-hostname TLS fails before HTTP for both TLS 1.2 and 1.3; the existing workers.dev origin succeeds. Cloudflare confirms the custom-domain registration and service, but SSL/certificate/DNS reads are denied. The cause is not established; no routing or certificate settings were changed. The custom-hostname gate remains FAIL.

Archive ZIP ETag, individual member CRC and SHA, and decoded CIK are verified. The large archive's declared full SHA was not independently rehashed. Publication uses create-only keys and readback equality; it never writes a CURRENT pointer. Licensed datasets were neither migrated nor disclosed to an LLM. Existing route regression checks emit only sanitized counts.

# Costs and measurements

See benchmarks.json for measured latencies/response sizes. These are sequential samples, not a load test or latency guarantee. API requests currently perform two R2 reads with no Basin query. At [R2 list prices](https://developers.cloudflare.com/r2/pricing/), two million Class B operations cost $0.72 before included allowances and billing rounding; storage is $0.015/GB-month. Worker request/CPU charges and account-wide allowance usage are additional and not measured here. Basin verification scans approximately 260,169 bytes per company query; five 10 MB minimum billable queries imply 50 MB before the included allowance, at the documented $0.0025/GB rate. Catalog/R2 operations are additional. These are scenario estimates, not an account bill or zero-cost claim.
