# SEC universe execution sprint

The existing public SEC archive is processed with one financial calculator and four bounded publication I/O tasks. A three-block 4MiB range cache avoids extracting or downloading the entire ZIP. Each member is checked against pinned ETag, local ZIP header/name, size, CRC and member SHA; the full archive SHA remains declared, not independently rehashed.

`python scripts/sec_universe_pipeline.py --maximum-spend 5` resumes gzip checkpoints and automatically passes 2,000, 5,000 and full-discovery stages. Independently reconciled Python/DuckDB outputs are required before company payload publication. Previously reconciled companies reuse hash-verified payloads and unchanged transformation identities; annual screening is recomputed from that payload. Failures remain explicit quarantines. Usable means at least one supported metric and period, not complete statements or financial certification.

The authorized incremental spend cap is $5. The conservative reservation includes a whole paid Class A and Class B operation unit plus first-month retained data; company materialization stops at 7GB, reserving headroom for catalog publication, bounded update composition and Basin experiments. It excludes existing subscription base charges and future months of retention. Local free-space and elapsed-time guards stop safely. Original archives, source releases and production CURRENT pointers are never rewritten.

A stable materialization-run identity owns company objects and checkpoints. Each catalog publication uses a separate identity derived from its exact checkpoint set. A later resume can therefore publish a new immutable snapshot without conflicting with an earlier partial publication. Hash-pinned, approved inherited source release IDs retain original payload provenance.

The private history API accepts `release_id` only for explicitly approved previous releases. `expected_release_id` still detects unwanted drift. Current and historical responses identify their serving release, materialization release and manifest hash; no caller-supplied object path or arbitrary SQL is accepted.

Metric-specific sorted screening chunks bound memory independently of universe size. Screening retains exact decimals/rationals, complete leaf-source IDs and missingness. See [terminal workflow](terminal-workflow.md), [screening contract](terminal-universe-screen.md), [Basin measurements](basin-optimization.md), and [controlled update limitations](updates-controlled-promotion.md).

Operational credential, TLS and historical-manifest blockers retain the exact actions in [current operator actions](operations.md); this sprint does not retry unauthorized provisioning or expand licensed access.

## Completed archive expansion

All 20,396 archived issuers were attempted. 15,224 have eligible US periodic source contexts; 5,172 are ineligible. 15,136 have at least one usable supported financial history. Quarantine contains 5,190 issuers without valid mapped histories and 70 source-identity mismatches, including 88 otherwise eligible issuers without usable mapped histories. No issuer is advertised as fully financially certified.

The immutable native release `0f0fa0be29d822e3b25e913239845c4702cddbfb7f60d2e0cf1661a8cea1a388` contains 8,576,461 normalized source revisions and 4,151,549 independently reconciled annual/quarterly/TTM outputs. Protected `sec-universe-sprint/coverage-quality.json` records metric/frequency counts, explicit gaps and source eligibility. Annual revenue is available for 9,262 companies; net income for 13,217; operating cash flow for 13,185; free cash flow for 7,192. Total debt remains particularly limited: only one company has accepted annual observations because component nonoverlap lacks sufficient evidence elsewhere. This is a mapping limitation, never filled with zero.

Processing used 107.6 minutes of wall time since the first completed checkpoint, including safe restarts and concurrent integration work. The final invocation took 1,156.9 seconds; it is not the full-run duration. Native retained publication data totals 6,522,557,784 bytes. Checkpoints survived interruption without promoting a failed issuer. The final invocation read 2,168,455,168 ranged source bytes with a 12MiB maximum cache; those counters are not cumulative across invocations.

The streaming composer published selective real SEC updates for NIKE and Costco as release `b39a670bad0670449256e59d38bf6b9600503449baded29c25e41d5fb368c6bb`, retaining the full native parent and original 441-company release. Independent raw-source checks and financial/context parity at the old cutoff passed. NIKE adds seven quarterly and five TTM outputs; Costco adds seven annual, six quarterly and five TTM outputs. Other issuers and the universe screener retain the September 24 cutoff. Per-company freshness, immutable raw candidate references and exact source terms are explicit in responses.

The current serving release has **4,151,579 reconciled outputs** including the selective updates. The final project suite passed **890 tests with 2 skipped**; operator Basin tests passed17. Actual staging rollback/restore and all three protected CURRENT hashes passed. The final combined budget reserves exactly **$5.00** after whole storage billing-unit rounding; as-run estimates are retained and actual account billing is unobserved.
